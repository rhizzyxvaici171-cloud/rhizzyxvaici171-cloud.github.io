What I build

I'm a software developer and cybersecurity-focused builder working across full-stack web and mobile development, backend systems, and application security. I care about what happens when a system is used the way it wasn't meant to be: what a malicious client could forge, what a server should never trust, and what a database should enforce on its own.

Track record

During an authorized security review, I discovered that an application had exposed API keys directly in client-side code, an oversight that could have led to significant, unplanned financial cost. I reported it and helped move the affected keys to secure server-side handling. It's the kind of small, overlooked detail that carries real financial risk, and it's why I treat security as part of the architecture rather than a final checklist item.
